2. Product Background
Libraries play an important role in supporting student learning and research. As the number of books and readers increases, the library needs to manage many different activities such as book management, borrowing and returning books, reservations, overdue books, fines and reader information.
For librarians, handling these activities takes a long time and is prone to errors while working. For students, finding suitable books can also become more difficult when the library has many books related to the major. Typical searches based primarily on title, author, genre, or book code may not always reflect the current student's learning needs, interests, or previous reading activities anymore.
Therefore, there is a need for a modern library system that can support both library activities and book discovery activities of students. SmartLibrary is proposed as a library management system for students, librarians and administrators, combining library services with AI-powered features to make library management and book searching more convenient.

4. Business Opportunity
As the number of books and readers keeps growing, libraries need management software to track core activities like managing books, managing readers, borrowing and returning books, reservations, and fines, all in one place. As data keeps increasing, managing everything by hand or with several disconnected tools becomes less efficient, more prone to mistakes, and harder for both librarians and readers to keep track of.
Besides the management problem, today's library systems are also limited in helping readers find books. The search function currently relies mainly on fixed fields like title, author, category, publisher, or publication year. This means readers need to know the exact keywords related to the book they want, while in reality, their need often comes from a topic, a learning goal, or a specific interest — something a normal keyword search cannot understand. As a result, readers can easily miss books that would actually suit them, simply because they didn't use the exact words the system expects.
The rise of Artificial Intelligence (AI) offers a way to solve this problem. Thanks to AI's ability to understand language the way humans do, the system can understand the meaning behind a search query instead of just matching keywords. It can also look at a reader's information and reading history to suggest books that fit each person's needs and interests.
Based on that, SmartLibrary is built to bring together basic library management functions and AI-powered features into one single system, making it easier to search for and discover books that truly fit each reader, while also helping librarians manage the library's main activities and workflows more efficiently.
5. Software Product Vision
For readers, librarians, and administrators who need a convenient and centralized way to access and manage library services, SmartLibrary is a web and mobile-supported library management system integrated with AI services. The system supports managing books, readers, borrowing and returning books, reservations, fines, book reviews, and notifications.
Unlike current library systems that mainly focus on book catalogs, SmartLibrary uses AI to help readers find suitable books based on their interests, learning goals, and reading history. The system offers book recommendations based on reader preferences and intelligent search capabilities, while also helping librarians manage library operations more efficiently.
The expected outcome is a modern and centralized library system where readers can easily find the right books, librarians can manage daily work more effectively, and administrators can uniformly manage library information and rules. SmartLibrary aims to improve library management and provide readers with a more convenient and personalized reading experience.
6. Project Scope & Limitations
The SmartLibrary project focuses on developing a centralized library management system that supports readers, librarians, and administrators. The system includes core library processes such as user and resource management, book and copy management, basic information search, borrowing and returning books, reservations, renewals, overdue book management, fines, evaluations, notifications, statistics, and library regulations. Additionally, the system integrates AI-powered services to suggest books based on needs and search by query meaning rather than just keywords. The project scope emphasizes practical library operations while utilizing AI to improve book search capabilities for readers.

6.1.4 AI Services
Personalized Book Recommendations
Recommend available library books using supported data such as Reader profile/major, saved reading preferences where available, borrowing history, and book ratings.
Semantic Book and Policy Search
Process natural-language queries.
Search indexed library books and policy/regulation documents using RAG and semantic embeddings.
Return relevant sources and catalog information.
AI-Assisted Acquisition Suggestions
Provide Librarians with suggestions based on indexed library information.
Suggestions are advisory; Librarians make the final acquisition decisions.
Library Operations Insights
Present available operational signals, such as circulation totals, popular borrowed books, Reader majors/categories, and ratings, to support staff review.
Overdue Status Indicators
Show existing overdue loans and apply a simple overdue-duration risk label.
This is not a predictive model that forecasts late returns before a book becomes overdue.
AI Service Administration and Indexing
Allow administrators to configure AI services, test provider connections, and manage access.
Synchronize the RAG data index.
